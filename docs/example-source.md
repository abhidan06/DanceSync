After reviewing the database terms and obtaining the source video, save it under
the local filename above and run from the repository root:

```powershell
.\venv\Scripts\python.exe main.py data/raw/group_dance_front.mp4 --output outputs/front_example
```

Use a new output folder for each run. Videos and full generated outputs are ignored
by Git. The README includes a supplied overlay screenshot and the original plot
PNG generated by the local analysis. The screenshot is illustrative; its exact
frame number is unknown. The plotted peaks are not labeled errors or ground truth.
